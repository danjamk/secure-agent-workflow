# Decisions

What was decided, why, who decided and who approved it, one file per decision, named `YYYY-MM-DD-<slug>.md`. `standards/decision-log.md` has the rules. This is a record: it doesn't grant approval, and GitHub's history of the linked PR settles any disagreement.

The log starts on 2026-11-05 with the decisions behind #8 (outbound handlers). Earlier decisions are in `docs/adr/` and in issue and PR comments. Until 2026-11-06 the entries were in one file, `docs/decisions.md`, which git history keeps.

To read them all in date order:

```bash
make decisions
```
